# 3D 모델링 보완 기준

기록일: 2026-09-06. 출처: 사용자가 ADV 리소스 제작기준서와 함께 전달한 3D 제작 요청.

## 사용자 지정

- 변신 연출을 위해 헤어·의상 파츠는 몸체와 분리하여 제작한다.
- 의상의 디테일한 부분도 파츠별로 나누어 제작한다.
- 의상에 가려지는 부위도 변신 연출에 필요하므로 바디 모델링을 전부 제작한다.
- 의상에 가려지는 부위의 부피는 Blender 기준 Shape Key로 조절할 수 있도록 작업한다.
- 엔진의 ToonShader를 이용해 카툰렌더링한다.
- 노말 처리에 관한 사용자 표현: “노말은 전부 밀어버릴것.”

## 확인이 필요한 용어

노말을 민다는 표현이 노멀맵 미사용, 커스텀 노멀 초기화, 버텍스 노멀 방향 통일·보정 중 어떤 작업인지는 확인 중이다. 이 표현을 임의의 Blender 명령이나 Unity 임포트 옵션으로 대체하지 않는다.

## 위키의 작업 정리안

사용자 기준을 실제 제작에 전달할 수 있도록 파츠 목록, 의상별 Shape Key 영향 범위·값·복원 시점, 변신 중간 관통 검사, 엔진 적용 결과와 납품 기록 항목을 추가했다. 헤어·옷깃·소매·리본 등은 분리 단위의 예시이며 새 캐릭터 디자인을 확정한 것이 아니다.

Shape Key 이름·개수, 리깅·내보내기 포맷, ToonShader 종류·버전, 임포트 옵션, 폴리곤·텍스처·머티리얼 예산은 TBD다. 이 자료는 모델 제작 가이드이며 실제 모델 생성·편집·발주를 지시하는 파일은 아니다.
