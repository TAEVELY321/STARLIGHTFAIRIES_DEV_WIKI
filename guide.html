캐릭터 문서 원작 대조 기록

대조일: 2026.09.06. 사용자가 제공한 《스타라이트 페어리즈》 원작소설 1~5권 DOCX를 기준으로 기존 16개 캐릭터 문서를 보강했다. 개요·특징·활동·가족·관계·주요 행적·어록을 정리했으며, 원문 파일은 수정하지 않았다.

기준과 범위

  • 화 제목은 소설 본문의 1~50화 표제에서 확인했다. 권별 구분명은 기존 위키의 명칭을 유지한다.
  • 각 캐릭터에는 실제 등장, 과거 회상, 기록·대화의 언급, 환영을 구분해 주요 행적을 수록한다. 이름이 나온 모든 문장을 세는 전수 출연표는 아니다.
  • 발화자와 문구를 대조한 대사만 어록에 싣는다. 환영의 말과 편지·소설 속 문장은 본인의 현재 발화로 바꾸지 않는다.
  • 프로필 수치·생일, 사용자 내부의 외전 계획과 테마곡은 소설의 본문 근거와 별도로 보존한다. 게임 수치·제작 규격은 기존 기획과 제작 가이드를 따른다.
  • DOCX의 표제·권 번호와 SHA-256은 novel-index.json에 기록한다. 인용 대사의 문단 번호는 제공 DOCX 본문의 추출 순서이며 페이지 번호가 아니다. 판본이 바뀌면 재대조가 필요하다.
  • 소설 전문과 개인 컴퓨터의 원본 경로는 웹 배포 자료에 포함하지 않는다.

시즈키와 카즈키 카즈키의 설명, 생존자의 증언, 되찾은 기억과 장치의 물증을 순서대로 구분한다. 3권 21~30화

요루의 책임 스승을 구할 수 있는 상황에서 관측을 선택했다. 교과 지식의 사실성과 학생을 이용한 의도를 분리한다. 4권 37~39화
스펙트라의 한계 사고 내부를 직접 본 것은 아니다. 힘 일부를 나눠 주어 쇠약해지지만 소멸하지 않는다. 3권 21화, 5권 44~46화
유우나의 몸 44화는 완전한 인간 회귀로 확정하지 않는다. 46화에 드러난 네메시스의 형태 유지·잠복과 구분한다. 5권 44~46화
유우나의 부재 책상과 책은 남지만 출석부에서 더는 이름이 불리지 않는다. 5권 50화
견본의 문구 실제 문구는 ‘이 이야기가 유우나의 하루를 조금이라도 따뜻하게 해 주기를.’이다. 5권 45·50화
마지막 사진 붉은 반지의 소녀가 단체 사진을 찍어 건넨다. 날아간 사진을 줍는 장면으로 쓰지 않는다. 5권 50화
아카리·나기사 아카리의 자료 조사·증거 보존·후방 보호, 나기사의 접객과 마을의 응원을 추가한다. 1권 1화, 2권 11·19화, 3권 2130화, 5권 4250화

별도 설정과 재확인 지점

  1. 마지막 붉은 반지 소녀의 이름은 소설 본문에서 공개되지 않는다. 기존 캐릭터 문서의 《크리스탈 페어리즈》 바톤터치 설명은 별도 확장 설정으로 보존한다. 유우나의 부활로 확정하지 않는다.
  2. 히이라기 자매의 11월 28일과 외전 공개 계획은 사용자 내부 설정이다. 본편 생일은 미공개로 유지하고 실제 출생일로 바꾸지 않는다.
  3. 5권 45화에서 치요가 유우나에게 이야기와 비 오는 날의 상처를 회고하는 대목은 1권 3~6화의 사건과 시간 관계를 추가 확인할 여지가 있다. 1권 해당 사건의 가해자는 에테르나이며 유우나의 학교 잠입은 2권 11화부터다. 문서에서는 45화의 대화가 있다는 사실을 기록하되, 이를 근거로 1권에 유우나의 미확인 행동을 새로 넣지 않았다.
  4. 개별 캐릭터 시트·내부 기획에만 있는 어원·고정 취향·외형·테마곡은 소설에 직접 쓰인 발언과 동일한 근거로 표시하지 않는다. 원작에서 확인된 생활 장면과 별도 제작 설정을 구분한다.

권장안기획서가 제안하는 방향. 확정 사양·본편 제작량이 아님.
프로토타입 검증구현·테스트 후 유지·변경을 결정할 잠정 설계.

3.추가 확인이 필요한 자료

  • 미정 설계의 결정 결과: 시작 선봉·AP 회복·교체/후열 처리·속도 검증, 성장·음성·저장·기술·출시 범위. 게임 기획의 결정 목록 참조.
  • 후속 개정본·확장 설정: 판본이 바뀔 때의 변경 내용, 붉은 반지 소녀와 후속작의 연결, 원작 대조 기록의 재확인 지점.
  • 캐릭터 제작 설정: 아직 신장·체중이 기재되지 않은 인물의 수치, 등신·정확한 색상·소재·의상 규격.
  • 추가 캐릭터 이미지: 설정화 페이지의 TBD 형태·인물과 의복을 착용한 체형 참고 시트.
  • 게임화 변경표: 원작 화와 게임 장면의 대응, 축소·확장·변경 사유.

4.편집·추가 방법

일반 열람은 index.html을 열면 됩니다. 생성된 HTML은 별도 서버 없이 동작하며, 검색·테마·모바일 메뉴에는 JavaScript를 사용합니다.

수정 대상파일
ADV·3D 제작 가이드scripts/resource-guides.mjs
배경·포즈·표정·화별 CG 표assets/resource-guide.json
게임 기획 내용scripts/game-design.mjs
기획 원본·보완 기준sources/design
원작 내용·신체정보sources/캐릭터_위키.md (기본 프로필의 신체정보를 상세 페이지·비교표에 공통 반영)
제작용 요약·형태 목록assets/characters.json
정면 표시 영역·설정화·팔레트assets/artwork.json
시트 원본 / 브랜드 이미지sources/CharacterSheet / sources/branding
페이지 구성·공통 문서scripts/build.mjs
디자인assets/style.css
검색·테마·메뉴assets/app.js

원본과 제작 정보를 수정한 뒤 Node.js 환경에서 npm install, npm run build, npm run check 순서로 실행하면 HTML과 검색 자료를 갱신할 수 있습니다. 재생성하면 생성된 HTML의 직접 수정 내용은 덮어씁니다.

위키 파일은 현재 내부 개발용 자료입니다. 표시 문구와 검색엔진 제외 설정은 접근 제어가 아니므로, 실제 공개 범위는 게시 환경에서 결정합니다.
