# 스타라이트 페어리즈 개발 위키

분홍색 계열의 정적 HTML·CSS·JavaScript 내부 개발 위키입니다. 배포 작업은 수행하지 않았습니다.

## 열기

index.html을 브라우저에서 열면 됩니다. 모든 문서는 정적 HTML이며, file:// 열람과 GitHub Pages 하위 경로를 지원하는 상대 경로를 사용합니다. 검색에 필요한 데이터도 로컬 JS 파일입니다.

## 내용

- 캐릭터 10명: 기본 프로필, 제작용 프로필, 원작 내용, 1~5권 화별 행적, 출처·게임화 메모
- 세계관·용어, 50화 통합 목차, ADV·3D 전투 기획, 제작 기준, 편집 안내
- 이름·변신명·본문 검색, 분류 필터, 권별 접기, 다크 모드, 모바일 메뉴, 인쇄 시 행적 펼치기

## 편집

Node.js 20 이상 권장. 의존성은 정적 파일을 재생성할 때만 필요합니다.

1. npm install
2. sources/*.md와 assets/characters.json 수정
3. npm run build
4. npm run check

생성된 HTML을 직접 수정하면 다음 build에서 덮어씁니다. 공통 문서 내용은 scripts/build.mjs, 디자인은 assets/style.css, 상호작용은 assets/app.js에서 수정합니다. 필요 시 npm run preview로 로컬 HTTP 미리보기를 실행합니다.

## 자료 기준

제공 캐릭터 MD 10개를 보관했습니다. 우미코는 사용자가 지정한 작업 폴더의 문서를 기준으로 반영했습니다. 원작소설 전문과 직접 대조한 것은 아닙니다. 제작 키워드는 원문 요약으로 표시했고, 신장·체중·쓰리사이즈 등 미확인 정보는 TBD입니다.

게임 기획은 이번 요청의 ADV, 전투만 3D, 원작과 같은 기본 스토리, 일부 변경·축소·확장 가능성을 적용했습니다. 세부 규칙·수치·게임 챕터 대응은 TBD입니다.

문서 내 가상 캐스팅은 확정 성우가 아닙니다. MD 첨부 식별자의 이미지는 제공되지 않아 실제 이미지로 연결하지 않았습니다. 캐릭터별 녹색·푸른색 등 고유 색은 원작대로 보존하고 공통 UI에 로즈핑크를 적용했습니다.

회사·게임 로고와 기존 저장소 파일은 보존합니다. 이 사이트에는 인증 기능이 없습니다. 내부용 표기와 noindex는 접근을 제한하지 않습니다.
