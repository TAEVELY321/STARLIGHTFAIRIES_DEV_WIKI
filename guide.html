2.문서 작성 기준

표기의미
확정 기준사용자 명시 규칙 또는 기획서의 확정 방향. 출처를 함께 기록.
권장안기획서가 제안하는 방향. 확정 사양·본편 제작량이 아님.
프로토타입 검증구현·테스트 후 유지·변경을 결정할 잠정 설계.
결정 필요후보·방향은 있으나 최종 결정이 필요한 항목.
원문 반영제공된 캐릭터 문서에서 확인한 설정. 원작소설 전문과 직접 대조했다는 뜻은 아님.
원문 기반 요약흩어진 묘사를 제작용 키워드로 묶은 항목. 추가 공식 설정이 아님.
제작용 분류모에요소·형태 목록 등 작업을 위한 분류. 구현 범위·수량 확정이 아님.
TBD현재 제공 자료로 정할 수 없는 정보. 임의 추정 없이 추후 갱신.
미공개 / 해당 없음원문 상태를 보존. 인간과 다른 존재의 나이·신체 규격 등은 적용 가능 여부부터 확인.

3.추가 확인이 필요한 자료

  • 미정 설계의 결정 결과: 시작 선봉·AP 회복·교체/후열 처리·속도 검증, 성장·음성·저장·기술·출시 범위. 게임 기획의 결정 목록 참조.
  • 원작소설 1~5권 전문 또는 기준 판본: 화별 행적과 용어의 최종 대조.
  • 캐릭터 제작 설정: 신장·체중·쓰리사이즈·등신·정확한 색상·소재·의상 규격.
  • 추가 캐릭터 이미지: 설정화 페이지의 TBD 형태·인물과 의복을 착용한 체형 참고 시트.
  • 게임화 변경표: 원작 화와 게임 장면의 대응, 축소·확장·변경 사유.

4.편집·추가 방법

일반 열람은 index.html을 열면 됩니다. 생성된 HTML은 별도 서버 없이 동작하며, 검색·테마·모바일 메뉴에는 JavaScript를 사용합니다.

수정 대상파일
게임 기획 내용scripts/game-design.mjs
기획 원본·보완 기준sources/design
원작 내용sources/캐릭터_위키.md
제작용 요약·형태 목록assets/characters.json
정면 표시 영역·설정화·팔레트assets/artwork.json
시트 원본 / 브랜드 이미지sources/CharacterSheet / sources/branding
페이지 구성·공통 문서scripts/build.mjs
디자인assets/style.css
검색·테마·메뉴assets/app.js

원본과 제작 정보를 수정한 뒤 Node.js 환경에서 npm install, npm run build, npm run check 순서로 실행하면 HTML과 검색 자료를 갱신할 수 있습니다. 재생성하면 생성된 HTML의 직접 수정 내용은 덮어씁니다.

위키 파일은 현재 내부 개발용 자료입니다. 표시 문구와 검색엔진 제외 설정은 접근 제어가 아니므로, 실제 공개 범위는 게시 환경에서 결정합니다.
