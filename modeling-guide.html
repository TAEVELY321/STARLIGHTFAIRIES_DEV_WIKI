3D 모델링 적용 기준

변신 연출을 위한 파츠 분리와 전체 바디 보존은 사용자 지정 기준입니다. 세부 분리 목록·Shape Key 이름·납품 체크 항목은 이를 작업에 적용하기 위한 정리안이며, 수치·엔진 설정이 명시되지 않은 부분은 TBD로 둡니다.

ADV·2D 제작 가이드 →규격·배경·스탠딩·CG·납품3D 모델링 가이드 →파츠 분리·바디·Shape Key·노말

1.몸체·헤어·의상 파츠 분리

사용자 지정 헤어와 의상 파츠는 몸체와 분리하여 제작합니다. 의상은 세부 장식까지 파츠별로 나눕니다. 변신 연출에서 개별 파츠의 등장·이동·전환을 다룰 수 있는 구조를 유지합니다.

분류작업 기준파츠 구분 예시
몸체변신 전후에 필요한 전체 바디를 보존. 의상에 가려진 영역도 생략하지 않음.Body
헤어몸체·의상과 분리. 변신에서 따로 제어할 부분은 구분.앞머리 / 뒷머리 / 옆머리 / 묶음 머리 / 헤어 장식
의상 본체의상 자체도 일체형으로 뭉치지 않고 상세 부분별 분리.상의 / 소매 / 옷깃 / 치마의 각 층 / 장갑 / 부츠
의상 세부 장식작은 디테일도 개별 파츠로 제작. 최종 구성은 해당 캐릭터 시트 기준.리본 / 프릴 / 레이스 / 브로치 / 보석 / 버클 / 테두리 장식
구성 기록오브젝트·파츠 ID와 변신 전후 사용 여부, 나타나는 순서·제어 대상을 목록화하는 정리안.변신 시퀀스·파츠 목록은 캐릭터별 TBD

위 예시는 분리 단위 설명이며 캐릭터에게 없는 장식을 새로 추가하는 지시가 아닙니다. 원본 모델에서는 파츠 분리 상태를 보존하고, 엔진용 결합·최적화가 필요하면 변신에서 개별 제어할 수 있는지 먼저 확인합니다.

2.전체 바디·가려진 부위

사용자 지정 의상 아래 가려지는 부위도 변신 연출에 필요하므로 바디 모델링을 전부 제작합니다. 해당 부위를 삭제해 의상 관통을 해결하는 방식으로 대체하지 않습니다.

상태제작·검수 기준
바디 기본형전체 몸체를 갖춘 기준 형태 보존. 캐릭터별 체형과 비율은 시트·승인 디자인을 따르며 미확인 수치는 TBD.
의상 착용형의상에 가려지는 부피를 Shape Key로 조절할 수 있게 작업. 의상별 필요한 범위를 구분.
변신 중간의상 파츠가 나타나거나 이동하는 동안 바디와 의상 사이 관통·빈틈·급격한 부피 변화가 없는지 확인.
리소스 구분모델링용 전체 바디 보존 기준이며 위키 대표 이미지의 공개 구도나 ADV 스탠딩 납품 범위를 변경하는 항목이 아님.

3.Shape Key를 통한 부피 조절

Blender 기준 의상에 가려지는 부위의 부피를 조절할 수 있는 Shape Key를 제작합니다. 기본 체형과 의상 대응 형태를 구분해 변신 연출에서 조정 가능한 상태로 전달합니다.

항목가이드 정리안 / 확인 사항
기본형원래 체형을 복원할 수 있는 기준 상태를 보존. 기본 체형 자체를 의상에 맞춰 영구 축소하지 않음.
조절 범위의상에 가려지는 부위를 대상으로 하고 실루엣에 드러나는 얼굴·손 등까지 일괄 축소하지 않음. 의상별 영향 부위와 사용 구간을 기록.
명명 예시Body_Fit_상의ID / Body_Fit_부츠ID 등 목적이 드러나는 이름을 제안. 실제 키 이름·개수·최솟값·최댓값·동시 사용 조합은 TBD.
연출 연동파츠 등장 전후에 사용할 값과 복원 시점을 시퀀스에 기록. 키 전환 중 꺼짐·돌출·의상 관통 및 여러 키의 조합을 검수.
엔진 전달실제 내보내기·임포트 후 형태 조절과 변신 애니메이션이 함께 작동하는지 확인. 포맷·리깅·엔진 연동 규격은 TBD.

4.ToonShader·노말 처리

사용자 지정 원문

“엔진에서 ToonShader를 이용한 카툰렌더링을 하기 때문에 노말은 전부 밀어버릴것.”

카툰렌더링용 노말 처리 요구를 적용 기준으로 기록합니다. 다만 ‘노말을 민다’의 구체적인 의미가 아직 확인되지 않아 노멀맵 미사용 / 커스텀 노멀 초기화 / 버텍스 노멀 방향 보정 중 어떤 작업인지 TBD로 둡니다. 임의의 Blender 명령이나 Unity 임포트 옵션으로 확정하지 않습니다.

5.모델 납품·확인 항목

아래는 사용자 기준을 전달하기 위한 납품 정리안입니다. 모델 제작·리깅·변신 연출을 실제 수행하거나 검수 완료했다는 뜻은 아닙니다.

  • 몸체·헤어·의상 본체·세부 장식이 구분된 편집 원본과 파츠 목록.
  • 가려진 부위까지 보존된 전체 바디와 원래 체형을 복원할 수 있는 기준 상태.
  • 의상별 부피 조절 Shape Key, 영향 부위·값 범위·사용 조합·복원 시점 기록.
  • 변신 전·중간·후 파츠 제어와 의상 관통·빈틈·체형 변화 검수 자료.
  • 노말 처리 방법 확정 후 적용 내역, 실제 ToonShader·임포트 조건과 결과 기록.
  • 원본과 엔진용 파일의 대응, 버전·담당자·검토 상태. 폴리곤·텍스처·머티리얼·드로콜 예산과 파일 포맷은 TBD.
