적용 기준

제작기준서 v1.0의 픽셀·컬러·납품 규격을 적용합니다. 수량은 원작 1~5권·50화를 기준으로 한 추천 예산이며, 신규 발주량·완성 수량·납기 보장이 아닙니다. 게임 1.0 출시 범위와도 별개입니다.

1.범위·수량을 세는 기준

54상태배경 30구도 + 추가 24상태
71세트몸 포즈 57기본 + 계획 14
40컷신규 풀 CG · 50화 전체
12~16구도부분 컷인 별도 예산
항목산정·변경 기준
배경장소가 아닌 카메라 구도를 기본 1종으로 계산. 54상태는 PNG 파일 수·상주 텍스처 수가 아님. 새 구도 예비 6종을 포함한 최대 구도 수 36종.
스탠딩인물 × 외형/의상 × 몸 포즈가 1세트. 표정 수와 별개. 71세트 + 예비 1세트인 72를 변경 승인 기준으로 사용하되 절대 상한으로 삼지 않음.
풀 CG인물·공간·구도가 완성된 신규 전체 화면 이미지. 같은 구도의 표정·눈물·조명·크롭·팬·줌은 새 컷으로 중복 집계하지 않음. 큰 자세·카메라 변경은 신규 구도 또는 고공수 차분으로 기록.
배분일반 화 0~1컷 / 주요 화 1~2컷. 예외 3컷은 40컷 안에서 재배정. 추가 예비 최대 10컷은 별도 승인. 0컷인 화도 표정·배경·음악·3D로 연출.
중복 방지3D 공격 장면을 CG로 중복 제작하지 않음. 35화 이별은 풀 애니메이션 별도 예산으로 정지 CG 0컷. CG 크롭·사진 추출은 신규 부분 컷인으로 중복 집계하지 않음.
기준 우선순위이 문서의 구체적인 2D 규격·추천 수량이 게임 기획서 v1의 일반적인 포즈·CG 권장 범위를 보완. 신규 스토리·외형 디자인 확정 자료는 아님.

2.픽셀·컬러·출력 규격

제작 규격 확정 연출 좌표계는 1920×1080 · 16:9입니다. 출력 해상도를 FHD로 제한하는 의미는 아닙니다.

분류원본 / 기본 납품적용 규칙
일반 ADV 배경3840×2160기본 가시 영역 3200×1800, 주변까지 채색
일반 이벤트 CG3840×2160기본은 전체 구도; 이동 연출은 별도 가시 영역
확대 특수 CG5120×2880콘티에서 4K 부족을 확인한 컷만 승인
캐릭터 스탠딩2048×4096, 투명주역 실제 몸 높이 약 3200~3600px
가로로 넓은 스탠딩최대 4096×4096몸의 픽셀 밀도 유지; 무기 분리 우선
얼굴·손 클로즈업2048×2048, 투명전체 화면 가로 컷인이면 2560×1440
가로 컷인2560×1440마스크·프레임은 일러스트와 별도
소품1024×1024 기본큰 클로즈업은 2048×2048, 장면별 승인
  • 일반 BG·CG는 4K 원화. 5760×3240을 중요도에 따라 일괄 적용하지 않습니다. 5K는 콘티에서 4K 부족이 확인된 컷만 승인합니다.
  • 게임 출력은 sRGB·채널당 8bit PNG. 배경은 불투명, 캐릭터·파츠는 RGBA 투명. CMYK를 사용하지 않으며 DPI는 화질 판정 기준이 아닙니다.
  • 5K 특수 CG도 기본 배포본은 3840×2160 축소본입니다. 확대 요구가 있는 해당 컷만 5120×2880 출력 사용을 승인합니다.
  • 1920×1080과 2560×1440에서 필수 화질 검수. 4K 출력은 UI·배치를 점검하며, 네이티브 4K 확대 품질 보장은 별도 제품 사양 TBD입니다.
  • 16:10·21:9에서는 16:9 구도를 보존하고 여백을 처리합니다. 자동 확장으로 미작화 부분을 노출하지 않습니다.
  • 원화 크기와 묘사 밀도는 별개입니다. 선화·기본색·정리된 명암을 표준으로 하고 FHD 축소본에서 읽히도록 마감합니다.

3.가시 영역·확대·이동

배경의 기본 가시 영역은 (320,180)~(3520,1980)입니다. 화면 밖 여백까지 채색합니다. 기본 상태에서 1080p 기준 이론적 평행 이동 여유는 좌우 ±192px·상하 ±108px이며, 흔들림·패럴랙스가 함께 있으면 한도를 줄입니다.

기본 사용 영역1080p 무업스케일 한계1440p 무업스케일 한계
배경: 3200×1800약 1.67배약 1.25배
일반 CG: 3840×2160 전체약 2.00배약 1.50배
특수 CG: 5120×2880 전체약 2.67배약 2.00배

원본 크기로 임포트하고 동일한 16:9 구도로 표시한 픽셀 계산입니다. 압축·회전·필터·배포본 축소·여백 크롭에 따라 실화질과 확대 한계는 달라집니다.

발주 전 콘티 기록적용 기준
기본·최대 구도기본 화면, 최대 확대, 이동 시작·끝 프레임, 얼굴·손의 최대 화면 크기를 러프에 표시.
일반 연출 범위1440p 검수 기준 BG 1.0~1.2배 / CG 1.0~1.5배. 큰 이동·2배 확대는 별도 리소스 검토.
클로즈업얼굴 원화가 부족하면 전신 캔버스 전체 확대 대신 얼굴·손 전용 클로즈업 제작.
UI 가림FHD 아래 280px(y=800~1080)을 대화창 영역으로 예약. 표정·손·핵심 소품의 가림을 확인하고 CG 감상 시 UI 숨김 지원.
CG 여백이동 여백을 모든 CG에 일괄 추가하지 않음. 전체 구도와 확장 구도를 나누고 원본 안의 가시 영역을 기록.

4.레이어·정렬·납품

대상보존할 구조·출력 기준
편집 원본레이어가 살아 있는 PSD 또는 CLIP, 호환용 레이어 PSD, 병합 미리보기 PNG. 편집 원본은 Unity Assets 밖에서 관리.
일반 배경BG_BASE / TIME_LIGHT / STATE_OVERLAY / OPTIONAL_FG
일반 CGBG / CHAR_A / CHAR_B / FX / GRADE 최소 구분. 승인된 이동·표정 교체에 필요한 범위로 분리.
가려진 영역2D는 승인된 이동에서 드러나는 배경·몸·의상을 채움. 3D 변신용 전체 바디 보존 기준과 구분.
스탠딩몸 / 얼굴 교체 영역 / 전경 머리카락 / 무기·소품 분리 가능 상태. 눈·입은 편집 원본에서 분리.
발바닥 기준2048×4096에서 (1024,3900), 좌상단 원점. 같은 인물의 포즈·의상별 몸 크기를 맞추고 신장 차이는 시트 기준. 미제공 신체 수치를 새로 만들지 않음.
정렬 메타데이터머리 기준선·FaceAnchor, 피벗·위치 오프셋. 패럴랙스 레이어는 동일 캔버스 또는 오프셋으로 정렬.
크롭·반전자동 크롭 금지. 오프셋 저장 출력기가 있을 때 허용. 좌우 반전은 비대칭 헤어·브로치·의상·무기 손을 해치지 않는 경우만 사용.
텍스트 분리대사·효과음 글자·UI 프레임을 이미지에 굽지 않음. 원고·성적표·간판의 현지화 문구는 별도 레이어/텍스트 리소스.

6.스탠딩·표정·추가 의상
